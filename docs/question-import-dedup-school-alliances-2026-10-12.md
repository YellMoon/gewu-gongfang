# 试题导入查重与学校、联盟资源关联

默认相似题提示阈值为用户选择的 90%，在导入页面可调整。完全相同的题干、选项和子题沿用云端原题 ID，补齐缺失答案、解析，合并体系节点及卷名、学年、年级、学期、考试类型、地区、学校或联盟标签。题干中的数值、公式、上下标、图片及表格结构差异不能触发完全重复合并。答案或解析有差异时保留原内容并在导入校验与历史详情提示。

资源学校新增学校／联盟类型。试卷导入和试题编辑通过资源 ID 多选关联，资源改名后读取名称同步变化。学生所属单位仍只能是学校；云端事务拒绝学生归属联盟、已有学生学校改成联盟，以及删除仍被试题引用的资源。旧单值字段及未传类型的旧客户端保持兼容，旧学校默认学校类型。

在线及离线恢复后的提交仍经过云端命令、权限和导入媒体凭据校验。完全重复合并使用租户级事务锁、原题锁及命令回执；重放同一命令返回原结果。NAS 只保存媒体和原件，不裁决业务合并。

考试组织方式与考试类型分开保存：校考、联盟联考、市级统考、多市联考、省级统考、全国统考和其他。覆盖地区采用多个标签，也可留空；市级或多市模拟考无需虚构学校或联盟。资源中的联盟可选择多所成员学校，一所学校也可加入多个联盟。成员关系不自动推定试卷或试题的覆盖地区。

例如杭州、宁波联合二模：考试类型为模拟题，考试组织方式为多市联考，覆盖地区为杭州市、宁波市，学校／联盟可留空；跨市联盟卷关联实际联盟，覆盖地区仅按试卷明确范围填写。完全重复题会合并不同来源的组织方式和覆盖地区标签。
