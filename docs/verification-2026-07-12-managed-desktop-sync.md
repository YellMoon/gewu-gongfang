日期：2026-07-12  
状态：当前工作树实现与本地验证通过，等待合并确认；尚未部署正式多端版本。

## 根因闭合

- 普通端空 `cloudBaseUrl` 与本机地址过滤共同造成空传输列表；现已改为只读托管正式云入口。
- 云网关此前缺少客户端发现所需的 `/api/cloud/host/status`；现已补齐鉴权状态接口、LAN 地址心跳字段和增量迁移。
- LAN 发现失败不再阻断云中继候选，传输探测保留结构化失败原因。
- 手机号自助配对已从服务、HTTP、桌面 UI 和小程序管理入口移除。

## 安全与身份

- 配对申请只接受设备 ID、设备名称和设备秘密；手机号、用户 ID、角色与 teacher_id 自报均被拒绝。
- 只有超级管理员可以从数据库真实用户中选择账号并批准设备。
- Electron 主进程使用 `safeStorage` 加密桌面会话，原子写入用户数据目录；渲染层只调用白名单 IPC。
- 旧 sessionStorage 会话只允许一次性迁移，迁移后删除旧值。
- 设备令牌绑定服务端批准用户和设备 ID；云同步仍校验已批准配对和用户状态。

## UI 证据

目标流程：应用加载 → 云同步入口 → 系统参数 → 普通端简易视图 → 未绑定设备状态。

- 1280×720：页面标题为“系统参数”，显示“本机与同步”“管理员托管”“当前设备尚未绑定同步账号”“申请绑定当前设备”。
- 敏感文案检查为 0：题库 SSD、备份目标状态、主数据库路径、题库移动硬盘路径、题库附件路径、阿里云服务地址、桌面端同步密钥、NAS 备份均未渲染。
- 手机号输入控件检查为 0；普通端只能申请当前设备。
- 900×700：`scrollWidth === clientWidth === 900`，无横向溢出、重叠或裁切。
- 运行时检查发现并修复了 JSX Unicode 转义被原样显示的问题；补充回归断言后重新构建和截图验证。
- 浏览器静态构建没有 Electron IPC，因此会记录“Electron API is not available”警告；Electron 安全存储由注入式单测和主进程语法检查验证，正式 Electron 重启验证留待打包安装阶段。
