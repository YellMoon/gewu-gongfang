# 旧同步草稿恢复与早课日期修复（2026-09-29）

桌面目标版本：8.9.23（从 8.9.22 自动判定 patch）。发布验证进行中。

## 问题与修复

- 旧草稿缺少 expectedVersion 时，适配器抛出错误而没有返回拒绝回执。
  native outbox 已经持久化 submitted，界面却只给 conflict 提供放弃入口，
  导致错误提示与“已确认，待完成”并存。已复现这一完整调用链。
- 缺版本、无效时间、缺对象 ID 和明确 NOT_FOUND 现在进入持久化 conflict，
  暂停自动提交。未知网络失败仍保留原命令，按原有规则重试。
- 所有未完成草稿恢复“放弃这条更改”；取消保留，确认后删除本机草稿，
  刷新投影与列表。不会调用云端业务删除接口；提交结果不确定时明确说明
  放弃不能撤销已经提交的云端操作。已完成历史继续隐藏。
- 不根据筛选后课程列表的缺席推断删除，不补造并发版本号、不强制覆盖
  云端、不自动丢弃用户未提交内容。课程表已不存在的旧更改可明确放弃。
- DailyView 原来按 start_time 字符串日期前缀筛选，但保存值是 UTC ISO，
  北京时间 08:00 前会落到前一天；周一凌晨还会从正确周消失。改用与周筛选、
  卡片时间、编辑和拖动一致的 dayjs 本地日期，不改变存储时间或云端协议。
