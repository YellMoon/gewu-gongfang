# 桌面题库完善（2026-10-05）

桌面版本 8.10.3。本轮按用户两张组卷网参考图和后续纠正恢复现有交互，沿用云端权威、离线整体确认、NAS 富媒体与现有组卷导出协议。

## 具体改动

- 新 TaxonomyManager 替换旧体系树后，没有接入圆形样式、行内输入及拖拽，是回退原因。现恢复名称右侧原位编辑、原位新增子节点和根节点；Enter 保存、Escape 取消；删除影响确认、备份及恢复保留。
- 展开为蓝色实心圆与白色减号，折叠为灰色实心圆与深灰色加号；叶子不显示圆圈。虚线连接同级节点及祖先层级；搜索保留匹配分支的祖先与后代。拖拽保持同级排序及跨层级移动，拒绝移入自身后代；清空父节点用显式空值经原云端草稿路径提交。
- 删除独立“查看答案与解析”按钮。点击试题区域、题卡空白或键盘 Enter/Space 抽出/拉回答案，使用可收起的动画区域，首次查看才渲染。编辑、删除、加入/移出试题篮按钮不触发抽拉；批量组卷仍进入 question-bank-paper。
- 预览原缓存键不含答案、解析、选项及结构化内容，实际复现修改答案后显示旧内容。改为不可变题目对象身份的弱缓存，避免旧内容复用及无上限保留；资源失败保留原题显示。
- KaTeX 结果共用有数量/字符上限的缓存；旧题干、选项的 HTML 转换按片段记忆，减少展开/收起答案时的重复工作。富媒体 HTML 先显示文字，图片分别到达后分别显示，单图失败不遮挡整题。
- 批量录入与问题提醒统一核对结构化/旧格式的题干、答案、解析、选项、单选多个答案、小题答案与未转换公式。云端结果与本地检查合并，不覆盖或降级失败。仅检查结构完整性与选项对应关系，不声称自动判定解题正确性。
- 搜索索引包含对象选项、结构化题干/答案/解析/小题、公式源码、题号、来源和标签。批量打标支持多个标签、去空白和去重；所有现有自定义体系均可批量关联，跨页选中题目不再静默漏过，保留失败选择并反馈数量。
- 试卷标题、答案位置、顺序、分区和分值保存为账户隔离的本地布局；返回页面恢复当前篮中题目，不复活已移除题。重新分组保留分值；切换是否包含草稿题保留被隐藏题的编辑。结构化题目及答案在组卷页使用统一渲染器。
