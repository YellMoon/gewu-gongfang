# 微信小程序审核与发布说明

适用项目：格物工坊小程序  
当前版本：`<当前版本>`

## 审核登录与体验范围

小程序只保留真实的微信手机号核验入口。审核员在登录页点击“验证手机号并登录”，授权审核员本人的微信手机号即可；不需要体验码，也没有合成管理员或合成学生角色。

已建档且绑定关系有效的手机号会进入对应正式账号。未建档手机号会被识别为“未认可学生”，进入受限体验账号：只能查看四道示例题、在隔离沙箱体验组卷及 Word/PDF 导出，并可提交学生或教师身份申请。该账号不会读取或修改正式业务数据，也不能访问正式课表、正式题库、财务、资产、用户管理、设备或同步数据。

身份申请会显示提交、审核中、驳回、配置中、通过后需重新登录等真实状态。审核员如不希望提交资料，可只检查示例题和导出流程；导出任务及文件短期过期，不写入正式题库、本地数据主机、OSS 或正式任务队列。

## 提交审核推荐填写

版本描述：

```text
登录页由用户手动填写手机号；已有档案首次绑定当前微信需超级管理员审核，未建档用户进入受限体验账号，可查看四道示例题、体验隔离组卷导出并提交正式身份申请。
```

测试备注：

```text
点击“验证手机号并登录”并授权审核员本人的微信手机号。未建档手机号会进入体验账号：可查看四道示例题、体验 Word/PDF 导出和提交身份申请；不会读取或修改正式教务数据。
```

建议设置：

- 测试账号/测试密码：不填写；审核员使用自己的微信手机号完成核验。
- 小程序订单中心 path：留空，当前小程序没有交易订单中心。
- 审核加急：默认不选。
- 用户隐私保护指引：选择“采集用户隐私”，并如实说明微信标识、手机号和身份申请资料的用途。

## 审核操作路径

1. 在登录页点击“验证手机号并登录”并允许微信提供手机号。
2. 未建档手机号进入体验首页，核对受限账号提示和四道示例题。
3. 选择示例题体验组卷、Word 导出和 PDF 导出；确认结果仅属于当前体验会话。
4. 打开“身份申请”，核对学生/家长或教师资料表单、确认提示与各申请状态；是否真实提交由审核员自行决定。
5. 打开课表和设置，确认体验账号只能看到明确空态与受限说明，然后退出登录。

如果审核平台需要验证正式角色，须在微信公众平台私密备注中提供一个单独准备且可撤销的正式测试手机号；不得把真实经营账号、密码或密钥写入仓库、小程序包或公开文档。

## 隐私字段、用途与保留

- 微信 `openid`/`unionid`：用于把同一微信会话绑定到唯一账号、防止手机号与微信串绑。
- 微信核验手机号：用于匹配现有正式身份，或建立未认可学生的受限账号。
- 昵称、头像（如微信返回）：仅用于账号展示和人工核验辅助。
- 身份申请资料：只用于管理员核验和把申请映射到本地学生、教师或管理员身份。
- 登录事件中的手机号，以及已驳回、已撤回或已批准申请中的手机号、申请载荷和驳回原因，在最后更新时间超过 180 天后自动脱敏；正式业务档案按业务与法定留存规则单独管理。

脱敏任务只记录处理数量，不输出手机号、申请内容或其他隐私明文。未认可体验账号的数据范围由服务端校验，修改客户端不能绕过正式数据防火墙。

## 提交前检查

1. 执行 `node scripts/check_miniapp_review_readiness.js`，确认文案、真实登录路径、隐私说明及已移除体验码的约束通过。
2. 执行 `npm run miniapp:release-check`，确认构建产物只使用 Backend 基址 `https://physicsedu.xyz/scheduling`，且不存在旧审核体验客户端。
3. 执行 `node scripts/check_review_demo.js`，确认 Gateway 旧 `/api/auth/review-demo` 与 `/api/review-demo/*` 路由固定返回 410，旧令牌不能进入 Backend。
4. 检查阿里云 Gateway `https://physicsedu.xyz/api/health` 和 Backend `https://physicsedu.xyz/scheduling/api/health`，版本必须与本次发布一致。
5. 确认微信小程序合法域名包含 `https://physicsedu.xyz`，并实际走一次授权手机号、体验题、导出和退出流程。

## 被驳回时的处理

若被驳回，保存驳回原因、页面路径和审核时间的截图；按文案/隐私、页面权限或网络/API 分类修复，随后重跑 readiness、构建和开发版上传核验，再重新提交。

## 审核通过后的处理

审核通过后，仍需在微信公众平台点击“发布线上版”。只有阿里云后端、小程序、本地数据主机、移动硬盘题库、NAS 备份和 OSS 桌面更新矩阵均有运行证据时，才能声明统一发布完成。

## 当前平台权限限制

Codex 可通过微信开发者工具上传开发版本；若普通小程序 AppSecret 调用审核 OpenAPI 仍返回 `86000 should be called only from third party`，“提交审核”和“发布线上版”必须在微信公众平台后台完成，并如实记录为外部平台阻断，不能把开发版上传描述为线上版已发布。
