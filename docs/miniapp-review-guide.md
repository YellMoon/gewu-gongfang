# 微信小程序审核与发布说明

适用项目：格物工坊小程序  
当前版本：`<当前版本>`

## 审核登录与体验范围

小程序支持已绑定微信直接登录；首次登录时由用户授权微信手机号。新手机号会自动创建访客账号，当前版本不需要体验码。

已绑定关系有效的微信会进入对应账号。新账号以访客身份进入：只能使用云端题目预览，并可提交教师、学生或家庭成员身份申请；教师和学生可选择新建档案或关联已有档案，家庭成员只能关联已有学生档案。访客不会读取或修改正式业务数据，也不能访问课表、财务、资产或同步数据。

身份申请会显示提交、驳回、通过后需重新登录等真实状态。审核员如不希望提交资料，可只检查访客题目预览和受限说明；访客没有组卷、Word/PDF 导出或核心教务写入权限。

## 提交审核推荐填写

版本描述：

```text
支持已绑定微信直接登录；首次登录需授权微信手机号，新账号自动创建为访客，可预览云端题目并提交教师、学生或家庭成员身份申请。
```

测试备注：

```text
审核员可用已绑定微信直接登录，或在首次登录时授权微信手机号。新账号以访客身份进入，只能预览云端题目并提交身份申请，不会读取或修改正式教务数据。
```

建议设置：

- 测试账号/测试密码：不填写；审核员使用自己的微信登录，并在首次登录时按微信提示授权手机号。
- 小程序订单中心 path：留空，当前小程序没有交易订单中心。
- 审核加急：默认不选。
- 用户隐私保护指引：选择“采集用户隐私”，并如实说明微信标识、手机号和身份申请资料的用途。

## 审核操作路径

1. 在登录页选择“已绑定微信直接登录”，或在首次登录时授权微信手机号。
2. 新账号自动创建访客身份，核对题目预览和受限账号提示。
3. 确认访客无法组卷、Word/PDF 导出、导入资产或修改核心教务数据。
4. 打开“身份申请”，核对教师、学生、家庭成员选项；教师和学生可选新建或关联档案，家庭成员仅能关联已有学生档案。是否真实提交由审核员自行决定。
5. 打开设置并退出登录；确认访客没有课表、财务、资产等业务入口。

如果审核平台需要验证正式角色，须在微信公众平台私密备注中提供一个单独准备且可撤销的正式测试手机号；不得把真实经营账号、密码或密钥写入仓库、小程序包或公开文档。

## 隐私字段、用途与保留

- 微信 `openid`/`unionid`：用于把同一微信会话绑定到唯一账号、防止手机号与微信串绑。
- 微信手机号授权：用于把微信登录与同一账号合并，并在首次登录时建立访客账号。
- 昵称、头像（如微信返回）：仅用于账号展示和人工核验辅助。
- 身份申请资料：只用于数据负责人审核，并把申请映射到云端学生、教师或学生家庭成员关系。
- 登录事件中的手机号，以及已驳回、已撤回或已批准申请中的手机号、申请载荷和驳回原因，在最后更新时间超过 180 天后自动脱敏；正式业务档案按业务与法定留存规则单独管理。

脱敏任务只记录处理数量，不输出手机号、申请内容或其他隐私明文。未认可体验账号的数据范围由服务端校验，修改客户端不能绕过正式数据防火墙。

## 提交前检查

1. 执行 `node scripts/check_miniapp_review_readiness.js`，确认文案、真实登录路径、隐私说明及已移除体验码的约束通过。
2. 执行 `npm run miniapp:release-check`，确认构建产物使用云端业务基址 `https://physicsedu.xyz/cloud-business`，且不存在旧审核体验客户端。
3. 执行 `node scripts/check_review_demo.js`，确认已移除的审核体验路由固定返回 410，旧令牌不能进入云端业务服务。
4. 检查阿里云云端业务健康端点 `https://physicsedu.xyz/cloud-business/api/health`，版本必须与本次发布一致。
5. 确认微信小程序合法域名包含 `https://physicsedu.xyz`，并实际走一次微信登录、首次手机号授权、访客题目预览和退出流程。

## 被驳回时的处理

若被驳回，保存驳回原因、页面路径和审核时间的截图；按文案/隐私、页面权限或网络/API 分类修复，随后重跑 readiness、构建和开发版上传核验，再重新提交。

## 审核通过后的处理

审核通过后，仍需在微信公众平台点击“发布线上版”。只有阿里云云端业务服务、小程序、NAS 存储代理和 OSS 桌面更新矩阵均有运行证据时，才能声明统一发布完成。

## 当前平台权限限制

Codex 可通过微信开发者工具上传开发版本；若普通小程序 AppSecret 调用审核 OpenAPI 仍返回 `86000 should be called only from third party`，“提交审核”和“发布线上版”必须在微信公众平台后台完成，并如实记录为外部平台阻断，不能把开发版上传描述为线上版已发布。
