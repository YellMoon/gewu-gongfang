# 微信小程序审核与发布说明

适用项目：格物工坊小程序  
当前版本：`<当前版本>`

## 审核体验入口

登录页永久保留独立的“审核体验”入口，普通微信一键登录流程不变。审核员点击该入口，输入提审备注中的体验码，再选择管理员体验或学生体验。体验码只由私密提审配置提供，不写入 Git、小程序包或公开文档。

管理员体验仅浏览明显虚构、已脱敏的只读示例，包括现有的首页、课表、学员、财务示例、资产示例和题库页面。学生体验仅查看与绑定的示例学生有关的课表和示例题，不会扩大到其他示例学生的数据。

审核体验中的示例题组卷以及 Word/PDF 导出在 Gateway 进程内的隔离内存沙箱完成；任务和文件短期过期，不会写入真实业务数据库、真实题库、本地数据主机、OSS 或主机任务队列。用户审核、财务导入、教务编辑、设备配对和同步等真实写入均被服务端拒绝。

## 提交审核推荐填写

版本描述：

```text
新增永久审核体验入口；管理员和学生角色仅浏览脱敏示例数据，并可在隔离内存沙箱体验示例题组卷及 Word/PDF 导出。
```

测试备注（提交前只在微信公众平台私密备注中，将占位符替换为本次部署的实际体验码；实际码不得回写本文件）：

```text
点击登录页“审核体验”，输入体验码 <review experience code>，选择管理员或学生。管理员浏览脱敏只读示例；学生仅查看绑定的示例学生。组卷与 Word/PDF 导出仅在隔离内存沙箱完成，不会写入真实业务数据。
```

建议设置：

- 图片预览：不强制上传。
- 视频预览：不强制上传。
- 测试账号/测试密码：使用上方审核体验入口和私密体验码，不填写真实经营账号密码。
- 小程序订单中心 path：留空，当前小程序没有交易订单中心。
- 审核加急：默认不选。
- 用户隐私保护指引：选择“采集用户隐私”，因为普通微信登录会涉及用户标识信息；审核体验自身不创建真实用户。

## 审核操作路径

1. 在登录页点击“审核体验”，输入私密备注中的体验码。
2. 选择管理员体验：核对脱敏只读的管理页面，并在题库选择示例题体验组卷、Word 导出或 PDF 导出。
3. 退出后重新进入审核体验，选择学生体验：只核对绑定的示例学生课表和示例题，并可在相同的隔离内存沙箱体验组卷导出。
4. 在“我的/设置”中点击“退出审核体验”，确认返回登录页。

错误体验码、过期会话、过期导出文件和网络失败会分别提示，不会回退到真实数据。审核体验没有用户审核、财务导入或教务编辑能力；看到只读提示是预期行为。

## 提交前检查

1. 优先使用密码管理器的加密随机生成器创建并保存体验码：至少 32 个 ASCII 字符，同时含大小写字母、数字和符号；不要使用项目名、产品名、角色、年份、日期、键盘序列或重复片段。强格式门禁只能排除明显可猜值，不是对随机性的数学证明。
2. Windows 本机也可用以下命令生成候选值并直接写入剪贴板；命令不会输出候选值。立即粘贴到密码管理器，随后清空剪贴板；不得粘贴到终端命令行、聊天、日志或 Git：

   ```powershell
   node -e "const c=require('crypto').randomBytes(32).toString('base64url')+'!aA1';const r=require('child_process').spawnSync('powershell.exe',['-NoProfile','-Command','Set-Clipboard'],{input:c,encoding:'utf8',stdio:['pipe','ignore','ignore']});process.exit(r.status??1)"
   ```

3. 使用候选值配置 `MINIAPP_REVIEW_EXPERIENCE_CODE`，只通过受控部署环境和微信私密提审备注传递。运行 `node scripts/check_miniapp_review_readiness.js` 确认文案与共享强格式策略通过；readiness 不会输出体验码。
4. 配置 `MINIAPP_REVIEW_BASE_URL=https://physicsedu.xyz/scheduling` 后运行 `node scripts/check_review_demo.js`，确认管理员和学生两条公开链路、沙箱导出签名及真实写入拒绝均通过。
5. 阿里云健康检查：`https://physicsedu.xyz/scheduling/api/health`，期望返回 `ok: true` 且版本与本次发布一致。
6. 微信小程序 API 合法域名包含 `https://physicsedu.xyz`。

## 被驳回时的处理

如果被驳回：

1. 截图保存驳回原因、页面路径、审核时间。
2. 对照驳回原因判断文案/隐私、页面功能或网络/API 类型，并复跑 readiness 与公开 smoke。
3. 修复后执行 `npm test`、`npm run miniapp:release-check` 和开发版上传核验，再重新提交审核。

## 审核通过后的处理

审核通过后，仍需在微信公众平台点击“发布线上版”。只有阿里云后端、公开审核体验 smoke、本地数据主机、移动硬盘题库、NAS 备份和 OSS 桌面更新矩阵均有证据时，才能声明统一发布完成。

## 当前平台权限限制

Codex 可通过微信开发者工具上传开发版本；当前普通小程序 AppSecret 调用审核相关 OpenAPI 仍可能返回 `86000 should be called only from third party`。若该限制持续存在，“提交审核”和“发布线上版”必须在微信公众平台后台完成，并如实记录为外部平台阻断；不能把开发版上传描述为线上版已发布。
