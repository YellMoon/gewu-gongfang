# 微信小程序审核与发布说明

适用项目：格物工坊小程序  
当前版本：5.14.3

> 当前审核阻断：生产登录仍要求手机号已获授权，审核员无法直接进入核心页面。
> 本版本先完成开发版上传；审核体验入口与独立脱敏演示数据将在既定后续任务
> “处理登录审核阻断”中实现后，再重新提交审核。现阶段不得使用下方旧测试备注
> 直接申报为可无障碍体验。

## 提交审核推荐填写

版本描述：

```text
修复云端接口与权限同步，完善小程序管理员/学生入口、课表查看、题库组卷导出、财务资产导入等现有功能联调。
```

测试备注：

```text
小程序支持微信一键登录。管理员入口包含首页、课程表、学员、财务、我的等页面；学生入口仅展示本人相关课表，并支持题库选题组卷和导出。
```

建议设置：

- 图片预览：不强制上传。
- 视频预览：不强制上传。
- 测试账号/测试密码：如审核要求再提供专用测试账号；不要填写真实经营账号密码。
- 小程序订单中心 path：留空，当前小程序没有交易订单中心。
- 审核加急：默认不选。
- 用户隐私保护指引：选择“采集用户隐私”，因为微信登录会涉及用户标识信息。

## 审核等待期检查

1. 阿里云后端健康检查：
   - `https://physicsedu.xyz/scheduling/api/health`
   - 期望返回 `ok: true`，版本与当前发布版本一致。
2. 小程序 API 合法域名：
   - `https://physicsedu.xyz`
   - 如审核提示网络异常，优先复查微信公众平台“服务器域名”。
3. 小程序功能边界：
   - 管理员：使用管理员入口和对应管理页面。
   - 学生：仅展示本人相关课表，并使用题库选题组卷和导出功能。
   - 不在审核说明中描述不存在或已删除的模块。

## 被驳回时的处理

如果被驳回：

1. 截图保存驳回原因、页面路径、审核时间。
2. 对照驳回原因判断类型：
   - 文案/隐私问题：修改审核说明或隐私指引。
   - 页面功能问题：修复小程序页面或接口。
   - 网络/API 问题：先验证阿里云健康检查、HTTPS、合法域名。
3. 修复后执行：
   - `npm test`
   - `npm run miniapp:release-check`
   - `npm run miniapp:upload -- --desc="<本次修复说明>"`
4. 重新提交审核。

## 审核通过后的处理

审核通过后，还需要在微信公众平台点击“发布线上版”。发布属于对外生效动作，应在确认以下事项后进行：

- 阿里云后端健康检查通过。
- 云中继 smoke 通过。
- 本地题库盘、NAS 备份、本地缓存 readiness 通过。
- 当前开发版版本号与计划发布版本一致。

发布后建议立即检查：

- 首页是否能正常进入。
- 管理员/学生入口是否按角色展示。
- 课表、题库组卷导出、财务资产导入入口是否可访问。

## 当前接口权限限制

Codex 已能通过微信开发者工具上传开发版本；但当前普通小程序 AppSecret 调用审核相关 OpenAPI 会返回 `86000 should be called only from third party`。因此“提交审核”和“发布线上版”当前必须在微信公众平台后台完成，或改接第三方平台权限后再自动化。
