# 管理员切换、试题行内公式与测试数据清理

## 修复

- 管理员切换要求两分钟内主动完成登录验证。旧界面对 `DESKTOP_IDENTITY_RECENT_UNLOCK_REQUIRED` 仅提示重试，没有恢复路径。保持安全时限，转入密码/微信登录，同一账号重新验证后自动继续切换；取消清除意图，不同账号不能继承管理员切换。
- 云端切换成功会撤销旧会话。响应丢失、格式异常或本地接受/保存失败时，标记会话不确定或已轮换，重新登录，避免恢复失效会话。
- 题干、选项、答案、解析在桌面、小程序及云端 Word/PDF 导出中默认行内显示公式，不再因 `formulaBlock`、`displayMode:block`、`$$` 自动另起一行。保留原文段落、硬换行、表格和 aligned/matrix 内部行，不修改存储原件。旧 HTML 先保护完整公式再格式化，避免拆坏分式或段落。
- 备份后通过云端带版本条件的 DELETE 接口删除 2 名测试教师、1 门测试课程、5 条关联测试排课。全量核对三张表中其他行未变；临时维护会话、设备、安装和关联均撤销，有效数为 0。
