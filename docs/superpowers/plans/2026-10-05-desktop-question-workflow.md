# 桌面题库完善实施计划

**目标：**按用户指定的蓝色圆形树节点、原位新增/编辑和拖拽调序恢复现有体系树，同时修复题库实际流程中可复现的缺陷。

**架构：**沿用云端业务权威、离线草稿与现有导出任务协议。本轮仅修改桌面呈现和本地检查/搜索/试卷布局，不增加核心业务写入入口，不改变其他端协议。

**技术：**React、Ant Design、KaTeX、现有 Node 测试和 Playwright 渲染验证。

- [x] 体系树：在 TaxonomyManager 中恢复行内输入，圆形展开控件、层级引导线、搜索定位；通过纯树操作检查同级排序、跨层级移动和循环拒绝，写入仍经过 updateTaxonomyNode。
- [x] 渲染：复现编辑答案后旧缓存的问题；按题目对象身份缓存资源解析，复用有上限的公式结果；保留原始内容、字体和公式语义。
- [x] 录入与核对：统一检查结构化及旧题目的题干、答案、解析、选项和未转换公式；合并云端检查而非覆盖；失败不得被警告降级。
- [x] 搜索与打标：对象选项及结构化各部分参与搜索；批量标签去除空白、去重；自定义体系纳入批量关联，错误保留失败选择并明确计数。
- [x] 试卷整理：重新分组保留自定义分值，保存当前标题、答案位置、分区、顺序与分值为账户隔离的本地布局；不覆盖云端试题。
- [x] 验证：先运行失败回归，再执行相关题库测试、类型检查、全量测试与真实浏览器交互/截图；在验证记录中区分实际通过与外部阻断。
- [ ] 发布：仅递增桌面版本；检查现有四端兼容证据，提交推送 gewu/master，构建并发布 OSS feed；恢复 Node native ABI，核验安装包、latest.yml 与发布状态。

已检查：现有 TaxonomyManager 使用 Modal.confirm 收集名称且无 draggable；旧 knowledge-tree 样式没有应用于新组件。QuestionPreviewCard 缓存键未包含答案/解析/选项。云端录入结果覆盖本地问题列表。试卷自动分组重建默认分值。搜索把对象选项转换成普通字符串。
