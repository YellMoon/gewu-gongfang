# 受管普通桌面端同步与角色隔离设计

日期：2026-07-12  
状态：用户已批准

## 问题与根因

普通桌面端当前默认 `cloudBaseUrl` 为空，同时默认 `hostBaseUrl` 为本机 `127.0.0.1:3001`；客户端传输选择会排除本机地址，最终没有任何候选传输并返回 `NO_SYNC_TRANSPORT_AVAILABLE`。现有同步配对还允许普通端填写任意手机号，授权会话仅保存在 `sessionStorage`，无法形成可信、持久的设备身份。系统参数页也没有按运行角色隔离，普通端能看到数据主机的题库盘、备份路径、数据库路径、云地址、同步密钥和危险数据管理入口。

## 目标

- 普通端无需填写云地址、主机地址或同步密钥即可发现可用传输。
- 普通端不能选择账号、填写手机号、声明角色或自行切换身份。
- 首次启动由设备发起不含账号选择的配对申请，超级管理员将设备绑定到真实账号并批准。
- 批准后的设备凭证跨重启持久化、可撤销，并绑定账号、设备 ID 与服务端批准记录。
- 普通端系统参数只呈现版本、设备、已绑定账号、连接与同步状态。
- 数据主机专属配置、状态和危险操作在普通端既不加载也不渲染，后端同样拒绝越权访问。

## 非目标

- 不允许静默上传离线更改；同步前预览和用户确认继续保留。
- 不改变本地数据主机的最高业务数据权威地位。
- 不让阿里云成为最高权威业务数据库。
- 不引入普通端长期账号密码体系；管理员管理入口仍使用既有管理认证。

## 身份与设备配对

普通端首次启动自动生成稳定设备 ID 和高熵设备秘密，向受管云入口提交设备名称、设备 ID 和公钥/秘密证明，不提交手机号、用户 ID、角色或 `teacher_id`。界面只显示设备名称、短时一次性配对码和“等待管理员批准”。

超级管理员在已有权限管理界面查看待配对设备，选择数据库中真实存在且可绑定的账号后批准。服务端原子写入设备、账号、批准者、批准时间和状态，并签发范围受限、可轮换、可撤销的设备凭证。普通端轮询交换成功后保存凭证；后续启动自动恢复身份。普通端没有账号选择器；换人使用必须由管理员撤销或解绑后重新配对。

持久凭证优先由 Electron 主进程通过 Windows DPAPI 加密后落盘，渲染进程只通过受限 IPC 读取会话结果，不直接接触长期秘密。若当前 Electron 版本无法安全使用系统凭据 API，则使用 Electron `safeStorage` 的平台加密能力；不得退回明文 localStorage/sessionStorage 作为正式持久方案。

## 同步传输与配置

正式云中继入口由发布配置提供并在运行时设为只读托管值，普通端 UI 不可编辑。启动后普通端先连接云中继：云端返回当前数据主机在线状态和经校验的局域网候选地址；同网时优先直连，不同网或主机暂离线时使用云中继队列。无论本地用户配置是否为空，都必须至少构造正式云中继候选。

传输探测保留每个候选失败原因并返回结构化诊断，不再把所有失败折叠为 `NO_SYNC_TRANSPORT_AVAILABLE`。用户提示至少区分：无法连接云服务、设备等待批准、设备凭证失效/被撤销、数据主机暂离线并已排队、没有合法传输配置。原始错误码只进入诊断日志，不作为唯一用户提示。

## 角色隔离与简易系统参数

普通端只显示：软件版本、设备名称/ID摘要、绑定账号摘要、批准状态、云连接状态、数据主机状态、最后同步时间、重新检测和重新申请配对。普通端不加载或显示运行角色选择、主数据库路径、题库盘及附件路径、候选盘符、storeId、本地缓存、NAS、主机地址、云地址、同步密钥、SSD状态、备份目标、服务端快照、重置或清空所有数据。

数据主机保留完整运维配置，但运行角色不能由普通端页面随意升级。主机身份必须由安装/受控配置确定。所有主机专属状态与写操作都增加服务端能力校验，避免只靠 React 条件渲染隐藏。

## 状态与错误处理

- 未配对：显示配对码和等待管理员批准，不显示手机号输入。
- 待批准：允许刷新状态或取消本机申请，不允许选择账号。
- 已批准：显示服务端返回的账号摘要和设备状态，自动启用同步。
- 被拒绝/撤销：清除本机可用会话，保留本地业务数据和待同步队列，提示联系管理员重新申请。
- 云不可达：保留队列，提供重试，不要求用户填写地址或密钥。
- 主机离线：通过云中继提交请求并明确显示等待状态，不宣称同步完成。
- 同步失败：保留待同步更改，显示可处理原因和诊断编号。

## 兼容、迁移与回滚

旧 `sessionStorage` 授权只可作为一次性迁移输入；服务端校验通过后换取新设备凭证，迁移成功立即删除旧会话。旧的手填手机号配对接口停止向新版普通端暴露，并在服务端拒绝客户端自报账号绑定。已有运行配置继续可读，普通端不再编辑敏感字段；主机配置不被迁移过程覆盖。

数据库变更只做增量并在部署前备份。若新设备凭证链路异常，可回滚应用与服务端代码并恢复数据库备份；不得清除普通端本地数据或待同步队列。发布必须覆盖桌面端、数据主机、阿里云和适用的小程序管理入口，任何端受阻均标记为部分发布。

## 验证与验收

- 失败优先测试覆盖：空用户配置仍有托管云传输、普通端不能提交手机号/账号/角色、管理员批准后绑定固定账号、撤销后立即失效、凭证跨重启恢复。
- HTTP 契约覆盖伪造账号、伪造角色、重放/过期配对码、错误设备秘密、并发批准和越权主机接口。
- UI 覆盖未配对、待批准、已批准、拒绝、撤销、云不可达、主机离线和同步成功/失败。
- 普通端运行时截图不得出现任何主机路径、题库 SSD、备份目标、云地址或同步密钥。
- 数据主机运行时仍能使用完整配置和维护能力。
- 真实 Electron 重启后身份仍存在；同步主路径能进入预览并完成直连或中继，而非返回无传输错误。
- 相关单测、完整测试、生产构建、打包运行时、原生依赖恢复和多端健康检查通过后才能声明完成。
