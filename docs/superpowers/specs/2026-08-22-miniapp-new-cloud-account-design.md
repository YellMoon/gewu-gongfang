# 小程序全新云端账户与会话设计

## 决策

小程序不迁移、不兼容、也不读取旧账户、旧手机号绑定、旧 JWT、旧人工审核或游客身份数据。小程序从零开始使用云端账户体系；云端是账户、角色、数据范围和业务数据的唯一写入权威。

首个超级管理员由云端部署配置中的**不可逆手机号校验值**识别。手机号明文不得进入仓库、数据库业务行、日志、接口响应或小程序包。首个管理员完成微信验证后获得 `super_admin`；其余新用户先获得无业务权限的已验证云端账户，只能由超级管理员在云端授予管理员、教师或学生角色及数据范围。

## 会话与数据流

1. 小程序通过微信官方能力取得一次性验证凭据；小程序不自报手机号、角色、账户 ID 或权限。
2. 云端验证凭据的受众、签发方、一次性消费与有效期，取得经验证的手机号校验值。
3. 云端按该校验值查找或创建新的云端账户：首个管理员命中配置校验值，其余账户为未授权账户。
4. 云端签发独立、短期、仅供小程序使用的会话票据。该票据不是旧网关 JWT，也不是桌面设备登记会话；其中不含原始手机号、微信凭据、密码或私钥。
5. 所有小程序业务请求由云端从会话解析账户、角色和数据范围，再执行云端业务读写。客户端传入的角色或范围一律忽略。

小程序的初始业务范围是云端已迁移并已验证的课程、排课与相关受限读取；新增业务写能力必须逐项批准并由云端命令接口执行，不能回退为旧网关或本地数据库写入。

## 账户和权限规则

- 首个超级管理员的身份只由云端部署期配置的校验值决定；配置缺失或格式错误时，拒绝引导式管理员创建。
- 同一已验证手机号稳定复用同一新云端账户；不同校验值不得合并账户。
- 新用户没有默认教师、学生、管理员或业务读取权限。管理员授权后，下一次会话刷新生效。
- 帐户被禁用、撤销角色或超出数据范围时，云端拒绝请求；小程序不得依赖本地缓存继续访问。
- 旧小程序账户、旧 `miniapp-session`、旧人工手机号核验、绑定待审和体验游客路由均不作为新成功路径的输入或回退。

## 错误与离线边界

- 微信验证失败、过期、重放或受众不匹配：拒绝，不创建账户或会话。
- 新账户尚未授予角色：返回明确的“等待管理员授权”状态，不泄露其他账户或业务数据。
- 小程序离线时不得登录、刷新会话或提交业务写入；仅可展示明确的离线提示和已经在本机安全缓存、且权限允许的只读内容。它不产生桌面端的 `awaiting_confirmation` 草稿。
- 会话失效、账户撤销或服务不可用：要求重新联网验证；不得尝试使用旧 JWT 或旧网关接口兜底。

## 安全边界

- 云端仅保存验证所需的最小化、不可逆身份关联；原始微信凭据与手机号不得写入业务审计、排错日志、receipt、outbox 或小程序存储。
- 小程序会话与桌面在线登记会话分域、分受众、分签名用途；任一票据不可用于另一客户端类型。
- 角色授予、数据范围变更和超级管理员初始化均为云端受控命令，具备审计记录与幂等语义。
- NAS 只存放题库富媒体、导入原件和备份；小程序账户与会话不得直接访问 NAS 或作为 NAS 写入凭据。

## 实施与验证门槛

实施前先建立独立云端小程序身份模块和测试，不复用旧网关登录实现。测试至少覆盖：首个管理员、普通新用户、精确重放、验证凭据过期/重放/错误受众、配置缺失、账户禁用、角色授予后的会话刷新、旧 JWT/旧人工审核状态的拒绝，以及客户端伪造角色或账户 ID 的拒绝。

小程序接入后，必须验证它只访问新云端身份和业务接口；旧登录、旧账户数据库与旧网关 JWT 不在新调用图中。完成整体目标后，先由 5.6-sol 独立审计；只有审计通过，才统一发布云端、桌面端和小程序。

## 非目标

- 不迁移旧小程序账户、旧微信绑定、旧人工审核记录或旧游客身份。
- 不通过小程序创建桌面设备登记、桌面离线草稿或本地数据主机权限。
- 不在本设计中发布、部署、上传小程序，或修改真实云端账号与业务数据。
