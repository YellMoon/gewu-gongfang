# 格物工坊云端业务权威架构强制契约

**状态：** 当前唯一总体架构约束；对活跃计划、实现、迁移和发布判断具有最高项目内优先级。

## 不可回退的目标

1. 云端是适用业务数据与题库结构化文字内容的唯一可写权威；账户、设备、角色、权限、会话、审计、任务状态和业务事务均在同一云端权威边界内裁决。
2. NAS 或受控存储代理只保存题库富媒体、导入原件、Word/PDF 产物、文件校验信息与备份；它不得裁决用户、权限或业务事务。
3. 统一桌面端只有一种安装包，可安装于任意电脑；运行时账户、角色、能力和数据范围决定权限，安装包不决定权限。
4. 新设备首次登录必须在线验证账号，验证成功后静默登记设备、安装实例和账户关联；不要求管理员审批、旧设备确认或主机人工放行。设备记录只服务于会话隔离、风险控制、撤销和审计。
5. 桌面离线修改仅进入本地草稿；恢复联网后展示影响与冲突，由用户确认后提交云端，禁止静默推送。
6. 旧桌面 SQLite、旧题库盘和旧业务数据是受保护迁移来源与观察期恢复材料，不是新系统的业务裁决者。切换前必须完成备份、影子迁移、增量追赶、空库恢复、校验和回滚演练。

## 适用范围

- 云端业务库承载学生、教师、课程、排课、收费、课耗、资产、题库结构化内容、关系、版本和审核等适用业务表。
- 云端业务服务负责所有正式业务命令的鉴权、幂等、并发控制、审计、outbox 和任务状态。
- 存储代理通过受限任务访问 NAS；富媒体对象与云端业务记录通过对象 ID、不可变版本、大小和 SHA-256 对应。

## 已取代的路线

旧的本地主机业务权威路线不得作为活跃实现依据。任何仅把云端定位为 control-plane、禁止业务数据迁往云端、或要求本地主机裁决正式业务命令的材料，只能作为历史或局部安全参考；若与本契约冲突，以本契约和 [云端权威 vNext 架构设计](2026-08-13-cloud-authority-vnext-design.md) 为准。

## 可执行保证

`scripts/check_cloud_business_authority_contract.test.js` 是本契约的自动门禁，并已接入 `pretest:authority-architecture`。它会校验活跃指令、总纲、交付记录和被降级的旧计划：一旦重新写入“本地主机保存全量权威业务数据”等冲突表述，或移除云端业务权威、NAS 富媒体边界、自动设备登记等必要声明，架构测试入口必须失败。

这项门禁保证未来工作不会再把旧路线误作当前总体架构；它不把尚未完成的云端业务 schema、真实迁移、NAS 代理、业务 API 或发布伪装成已完成能力。
