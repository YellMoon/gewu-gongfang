# 机构学生统一费用链路设计

## 目标

把机构排课的收入和教师课时支出纳入现有学生费用模型：每个机构拥有一个自动维护的“机构名称+学生”，机构排课和混合班可像绑定普通学生一样绑定它。由此删除课程级纯机构费用编辑和课表独立机构费用窗口。

## 数据模型与生命周期

机构学生是 `students` 表中的真实记录，`source_type=2`、`institution_id=<机构 ID>`，名称为 `${机构名称}学生`。创建机构时同事务创建；初始化时对已有机构幂等补齐；机构改名时同步自动机构学生名称。若机构学生或机构已被课程、课表或财务记录引用，删除操作必须保留引用完整性并给出明确错误。

机构学生与普通机构生源的区别由可测试的识别规则确定：同一机构中名称符合自动命名且带有自动身份标记的记录才是机构学生。为避免仅凭名称误判，数据结构增加可同步的机构学生属性；旧数据由补齐逻辑生成该属性。

## 课程与定价

当课程来源是机构排课或混合班且已选择机构时，学生选择器包含该机构学生；机构排课的默认主费用承载者就是该机构学生。课程保存 `student_pricings`，学费和教师课时费均在该学生定价项中编辑。课程级 `price_tuition` / `price_teacher` 不再为“无学生的纯机构课”提供直接编辑或计算兜底。

来源或机构变化导致已选学生不再合法时，表单明确清理不合法绑定，避免跨机构挂账。未选择机构时机构学生选择处于禁用或空态并解释原因。

## 课表与财务

新课表从课程复制真实机构学生定价，出勤、学费收入和教师课时支出均走现有 `student_pricings` 快照。`financialDetails` 不再创建 `__institution_unbound__` 虚拟条目，也不再从课程级纯机构费用构造账目。

课表编辑只保留“学生出勤和费用”对话框。机构学生与其他学生使用同一列表、状态和费用字段，不再切换标题、保存消息或渲染“本节机构排课费用”卡片。

## 兼容与错误处理

自动补齐幂等且不覆盖用户创建的普通机构生源。旧课表已经保存的学生费用快照继续按原值展示和统计；缺少学生定价的旧纯机构课程不再允许继续依赖课程级费用，用户需在课程信息中绑定自动机构学生后刷新后续课表。所有跨实体写入优先使用事务，失败时不产生孤立机构或孤立机构学生。

## UI 方向

客户端是高频桌面教务工具，方向为 calm-operational / guided-confident。保留 Ant Design 现有紧凑密度、字体、颜色与表单顺序；第一视觉信号是“课程绑定了谁以及该学生的学费/课时费”，主操作仍是保存。删除重复窗口与特殊卡片，不增加装饰、虚构指标或新入口。

## 验证

测试覆盖机构学生生命周期、候选过滤、定价持久化、课表快照与财务汇总，并用真实桌面运行时验证添加机构、添加机构课程、打开课表费用窗口的主路径。检查空态、禁用态、焦点顺序、无重叠裁切和控制台错误。
