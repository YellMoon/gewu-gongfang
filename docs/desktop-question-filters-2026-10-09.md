# 桌面试题库筛选栏与手动调整

本次修正试题篮的位置、体系备份入口和试题标签筛选，保留当前题库数据与云端写入边界。

最上方标题显示“物理题库”等当前科目名，标题右侧下拉统一切换体系树、筛选条件和试题数据；底层页面名和路由保持不变，不再在树和筛选栏重复设置科目选择器。所有筛选项使用背景色块，统一左侧内边距与标签宽度。

## 使用方法

- 试题篮悬浮在主界面上，拖动可横向、纵向移动。松开后保存位置；点击打开试题篮，拖动不会误打开。窗口缩小时限制在可见区域内，不预留独立空白列。
- 体系区域移除“删除备份”入口。删除体系或节点时原有的自动快照、影响确认和审计仍由现有流程处理。
- 考试类型单独成行；题型和发布状态、难度和年级与学期默认合并显示，以浅背景色区分。点击多个选项即可多选，再次点击可取消；“全部”清空该行限制。同一行普通选项使用“或”匹配。
- 学年点击“＋”后输入搜索，在实时下拉列表中选择一个候选并点击“确定”。可以连续添加多个学年，点击文字标签右上角的叉号删除。候选由当前年份和题库已有学年组成。
- 左侧体系树卡片宽度稳定为约 264 px，树节点使用 13 px 字号和紧凑行距。节点操作按钮在悬停或聚焦时出现，长名称可换行；侧栏内部滚动。点击体系名称可独立收起/展开，保留树节点展开状态，搜索时临时显示结果，清空搜索后恢复收起状态。
- 体系标签直接使用当前学科已创建的体系名称。默认显示按体系顺序排列的前三个体系（不足三个则显示实际数量），每个体系都有“包含”和“排除”两个“＋”。超过三个时点击“添加新标签筛选”按顺序追加。
- 体系标签支持按名称模糊搜索。候选显示完整父级路径，确认后变成无边框文字标签。同一节点不能同时包含和排除；原有包含条件逐组满足、排除条件排除命中项的规则保持不变，选父节点时覆盖其后代。
- 左侧体系树右键节点，可选“选定为包含标签”“选定为排除标签”“取消标签筛选”，与筛选标签双向同步。选定第四个及之后的体系节点时自动显示对应行。
- 当前学科没有体系时，“添加新标签筛选”提示先建立体系并为试题打标，不虚构知识点、题型或模型体系。

“添加新标签筛选、更多筛选、重置、在结果中搜索”位于同一工具行，最右侧显示结果数量。输入后按回车或点击搜索，只搜索题干、选择题选项及实验题/解答题的小题，不搜索答案、解析和标签。

## 手动调整

点击考试类型行最右侧的“调整筛选栏”，可直接修改：

1. 勾选要显示的筛选行。取消显示时清空该行条件，避免隐藏条件继续限制结果。
2. 使用上移、下移箭头调整行顺序。
3. 勾选“合并固定选项到同一行”使用紧凑布局；取消勾选可将每类恢复成独立行。
4. 修改行间距和标签栏宽度，实时查看效果。默认上下内间距为 3 px，优先保留首屏试题区域。
5. 点击“恢复默认布局”恢复布局默认值。

设置保存在当前电脑、当前账号的分区中，按学科分别记住；刷新或重新打开页面仍保留。不修改体系名字或题库业务数据，不生成云端命令。

## 验证

执行 `npm run test:question-filters` 验证完整试题库页面；设置环境变量 `QUESTION_FILTER_RUNTIME=electron` 可在 Electron 中运行同一隔离数据流程。执行 `npm run typecheck`、`npm run test:taxonomy` 与 `npm test` 验证类型及相关回归。

浏览器脚本在独立临时目录输出截图和 `checks.json`，覆盖分行多选的真实查询结果、多个学年、体系搜索/包含/排除/树右键、追加体系、无体系提示、布局持久化、悬浮按钮拖动与窗口边界。使用独立账号分区和测试数据，不操作真实业务题库。

这次仅桌面界面和派生查询索引改变。云端接口、云端数据库结构、NAS 存储协议及小程序源码保持兼容。正式发布状态以版本矩阵记录和 OSS 验证结果为准；已有小程序开发上传记录不能代表生产发布完成。

实际验证：Chrome 与 Electron 均通过 11 组交互检查；1200 px 窗口下七字二级节点文本宽 91 px、可用宽约 180 px、行高 19.5 px、树卡片宽 264 px，1366 × 768 首屏完整显示第一道试题。类型检查、体系数据与删除保护、原有树编辑/拖动与公式排版、分页、批量操作和本地查询回归通过。全量 npm test 仍有与本次改动无关的 cloud-business-api/src/billFileDecoder.test.js 合成 PDF 金额提取失败，单独复现为 13 通过、1 失败。现有 antd Modal 废弃属性警告保留记录，无页面运行错误。
