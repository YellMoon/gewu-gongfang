# 专题题集导入

桌面导航“题库管理”改为“试题导入”，“试题库”改为“题库”。内部路由保持不变，当前科目标题仍显示“物理题库”等。

导入说明默认展开，文件选择后可在解析前点击“取消选择”。

新增 Word 导入格式“专题题集”，用于按主题汇集同类题目的文件。选择格式和文件后点击“开始解析”，在本机解析与预校验，校对后再生成待提交草稿，沿用原有云端确认提交和原件归档流程。

## 识别规则

- 按题号识别独立试题，以紧随题目的“【答案】”和“【详解】／【解析】／【分析】／【解答】区分答案与解析，不将解析步骤或表格里的小数误识别为新题。
- 文档题型分节用于识别单选、多选、填空、实验和解答题；保留选项、小题、表格、正常题图与可编辑公式。
- 删除题号之后、题干开头的来源信息括号，例如含考试年份、联考、二模的来源标记；不写入地区、学校、学年等字段。普通括号和小题序号保留。
- 共用材料或合并答案，却标成多个独立题号的题组整组跳过，不自动拆分或合并。页面提示原文题号和原因；只有这些题组时仍显示提示，不生成空导入任务。
- 导入卷名取文档标题，保留原始文件名和原件校验和。原件内容不改写；解析时清理微小标识图片不影响原件。

答案统一属于整道题，原文答案中的（1）（2）等结构原样保留在主答案，不拆入小题答案字段。

## 样本验证

《光学热学实验》前 52 题可独立导入；最后 53、54、55 三个题号属于一个共用材料题组，按用户要求跳过并提示。《配速法》可独立导入 7 题，7 处开头来源括号已移除。各题保留题干、答案、详解及其引用的公式和图片。

回归覆盖来源括号与普通括号、整题答案保留、小数表格、合并答案和共同答案题组的跳过、全部跳过的空结果、公式和图片、原件不变以及临时文件清理。原有讲义和试卷格式沿用原解析器。

新格式在桌面本机解析；归档任务沿用既有 lecture 传输类型，元信息 importFormat 标记 topic。云端和 NAS 契约保持兼容，本机解析器校验和覆盖新格式及既有公式／媒体转换代码。

运行 npm run test:question-intake 检查解析与云端边界，运行 node src/pages/QuestionBankImport.topic.browser.test.cjs 验证页面。可用 QUESTION_TOPIC_FILES 指定原件路径 JSON 数组，QUESTION_TOPIC_RUNTIME=electron 验证 Electron。测试只执行本机预览，不导入真实业务数据。
试题编辑器去掉 H1/H2/H3 标题按钮，上下标改用中文名称。图片默认独占一行，可用鼠标拖动调整位置或移到其他内容区域，右上角×删除。只在选中图片后显示尺寸和对齐控件，删除可独立撤销，图片的剪切、粘贴和替代文本控件已移除。
