# 操作日志与列表序号

## 现状与修复

旧操作日志 GET 本机 `/api/ops/audit?limit=300`，失败后将本地记录全部映射成 success；筛选仅覆盖取到的300条，时间排序反向。现在读取云端鉴权接口 `/api/desktop/operation-audits`，云端筛选/计数/分页，时间从新到旧，不再用本地草稿补成成功记录。

云端先持久化不可变操作请求，实际业务响应返回前追加不可变结果。开始记录失败则不执行业务；结果落库失败则保留原业务响应并显示“结果待确认”。管理员查看本租户，老师查看本人操作。详情展示安全提交字段与返回版本，不冒充修改前后快照。未曾留下证据的历史操作无法补造；异步任务成功表示提交成功，具体任务进度仍在原任务页。覆盖边界见 `cloud-business-api/sql/operation-audits.md`。

桌面所有 AntD 业务表格采用 `NumberedTable`：排课、课程、费用明细/各统计汇总、教师、学生、缴费、学校、机构、教室、资产、设备、角色申请、操作日志、同步日志、题库导入/工具/审核等。按可见顺序连续编号，分页20条时第2页从21开始；排序、筛选、页大小变化、服务端分页和无分页均保留正确顺序。导入中的原始序号改称“原文题号”，与可见序号分开。

手写记录列表也补齐：今日课程、待排课程、同步草稿、问题试题队列、导出任务、费用分组、资产分类、导入邮件、体系备份/冲突和题目版本。题库浏览、试题篮、组卷原有序号保留，不给原题表格或导航菜单增加数字。

小程序18个注册路由已盘点：排课、排课详情、学生、学生详情、课程、教师、缴费、统计、资产、组卷导出任务共10页补序号；题库和组卷已有编号保留。局部390px渲染截图见 `output/list-numbering-20260930/miniapp/`，不等同整套微信运行时UI验收。
